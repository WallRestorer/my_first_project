# Ответы на вопросы (Практическая работа №4: Flexbox)

## 1. Какое свойство включает Flexbox?
`display: flex;` — включает Flexbox. Дочерние элементы становятся flex-элементами и выстраиваются в ряд по умолчанию.

## 2. Разница между `justify-content` и `align-items`
- `justify-content` — выравнивание по **главной оси** (main axis).
- `align-items` — выравнивание по **поперечной оси** (cross axis).

**Пример:** `justify-content: center` центрирует по горизонтали, `align-items: center` — по вертикали.

## 3. Свойство `flex-direction`
Задаёт направление главной оси:
- `row` (по умолчанию) — слева направо.
- `row-reverse` — справа налево.
- `column` — сверху вниз.
- `column-reverse` — снизу вверх.

## 4. Сокращение `flex: 1`
Означает `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`.
- `flex-grow` — как сильно элемент растёт.
- `flex-shrink` — как сильно сжимается.
- `flex-basis` — базовый размер до распределения.

## 5. Свойство `flex-wrap`
Позволяет элементам переноситься на новую строку, если не хватает места.
- `nowrap` (по умолчанию) — всё в одну строку.
- `wrap` — перенос на новую строку.
- `wrap-reverse` — перенос в обратном порядке.

## 6. Разница между `align-content` и `align-items`
- `align-items` — выравнивает элементы **внутри одной строки**.
- `align-content` — выравнивает **сами строки** (работает только при `flex-wrap: wrap`).

## 7. Свойство `order`
Меняет порядок отображения элементов. По умолчанию `order: 0`. Чем меньше значение, тем раньше элемент.

**Пример:** `order: -1` переместит элемент в начало.

## 8. Main axis и Cross axis
- **Main axis (главная ось)** — направление, заданное `flex-direction`.
- **Cross axis (поперечная ось)** — перпендикулярна главной.

Если `flex-direction: row`, то main axis — горизонтальная, cross axis — вертикальная.

## 9. Адаптивность без медиа-запросов
С помощью `flex-wrap: wrap` и `flex: 1 1 300px`. Карточки сами переносятся на новую строку, когда не хватает места.

**Пример:**
```css
.cards-row {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}
.anime-card {
    flex: 1 1 300px;
}
