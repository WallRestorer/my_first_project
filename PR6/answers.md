# Ответы на вопросы для самоконтроля (ПР №6)

## 1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?
Мета-тег `<meta name="viewport" content="width=device-width, initial-scale=1.0">` сообщает браузеру реальную ширину экрана устройства. Без него медиа-запросы не работают корректно на мобильных.

## 2. Какие основные подходы к созданию адаптивных макетов вы использовали (Fluid, Adaptive, Responsive)?
Fluid (плавные `%`, `vw`, `fr`), Adaptive (медиа-запросы на фиксированных брейкпоинтах), Responsive (комбинация обоих).

## 3. Как работает Mobile First подход и в чем его преимущества перед Desktop First?
Базовые стили пишутся для мобильных, затем через `min-width` добавляются стили для десктопа. Плюсы: меньше кода, быстрее загрузка, приоритет мобильному трафику.

## 4. Какие единицы измерения наиболее предпочтительны для адаптивной верстки и почему (%, rem, em, vw/vh)?
`%` — для ширины, `rem` — для шрифтов и отступов, `em` — для зависимости от родителя, `vw`/`vh` — для привязки к экрану, `fr` — для Grid/Flex.

## 5. Как функция clamp() помогает создавать адаптивную типографику?
`clamp(мин, vw, макс)` плавно масштабирует шрифт в заданных границах без лишних медиа-запросов.

## 6. Какие основные брейкпоинты вы использовали и как определили эти значения?
1024px (планшет), 768px (мобильные, переключение меню), 480px (маленькие экраны) — самые популярные разрешения устройств.

## 7. Как медиа-запросы @media помогают создавать адаптивные стили? Приведите пример синтаксиса.
Применяют CSS при выполнении условия. Пример: `@media (max-width: 768px) { .nav-menu { display: none; } }`.

## 8. В чем разница между max-width и min-width в медиа-запросах и когда использовать каждый?
`max-width` — стили для экранов ≤ значения (Desktop First). `min-width` — для экранов ≥ значения (Mobile First).

## 9. Как сделать изображения адаптивными и какие CSS-свойства для этого используются?
`max-width: 100%; height: auto;` — изображение не выходит за контейнер и сохраняет пропорции.

## 10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?
DevTools: режим адаптивного дизайна, эмуляция устройств, панель Elements, Network, Lighthouse.
