# Ответы на вопросы (Практическая работа №3)

## 1. Разница между селектором по классу и по ID
**Класс (`.`):** специфичность 0,0,1,0. Можно использовать многократно. Для групп элементов.
**ID (`#`):** специфичность 1,0,0,0. Уникален на странице. Для одного конкретного элемента.

## 2. Как работает каскад в CSS
Порядок применения при конфликте:
1. `!important` (высший приоритет).
2. Источник (автор > пользователь > браузер).
3. Специфичность селектора.
4. Порядок объявления (ниже — приоритетнее).

## 3. Расчёт специфичности
| Селектор | Специфичность |
| :--- | :--- |
| `ul li.important` | 0,0,1,2 |
| `#site-title` | 1,0,0,0 |
| `.content > .featured-post` | 0,0,2,0 |

## 4. Наследуемые и ненаследуемые свойства
**Наследуются:** `color`, `font-family`, `font-size`.
**Не наследуются:** `margin`, `padding`, `border`.

## 5. Селектор `>` vs пробел
`>` — только прямые дети.
Пробел — все потомки (дети, внуки, правнуки).

## 6. Псевдоклассы `:hover` и `:nth-child()`
`:hover` — при наведении (кнопки, ссылки).
`:nth-child()` — по порядку (чередование строк, списков).

## 7. Правило `!important`
Игнорирует каскад и специфичность. Использовать с осторожностью — усложняет отладку.

## 8. Псевдоэлементы `::before` и `::after`
Добавляют контент до/после элемента. Обязательно свойство `content`.

## 9. Порядок при одинаковой специфичности
Побеждает правило, объявленное **ниже** в файле.

## 10. Инструменты разработчика
**Elements** — просмотр и редактирование стилей.
**Styles** — какие правила применяются, какие перекрыты.
**Computed** — итоговые значения.
**Device Toolbar** — проверка адаптивности.
